Security: Next.js encourages security best practices: enforce a Content Security Policy (CSP) via headers (see official guide), sanitize inputs, and never expose secrets to the client. Environment variables (NEXT*PUBLIC* prefix for client) are managed per runtime. Use next-secure-headers or built-in headers() configuration to harden requests.
